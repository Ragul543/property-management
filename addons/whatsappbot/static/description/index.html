WhatsApp Connector for Odoo

Integrate WhatsApp messaging with your Odoo system.

Features

Send WhatsApp messages directly from contacts
Receive incoming messages via webhook
Full message history with logging
Media support (images, documents, videos)
Partner integration with WhatsApp verification

Configuration

  1. Go to WhatsApp > Configuration > Settings
  2. Enter your WhatsApp bot server URL
  3. Enter your API key
  4. Click "Check Status" to verify connection
